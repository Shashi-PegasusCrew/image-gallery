#  Image Gallery Website

A modern, responsive Image Gallery website built using **HTML, CSS, and JavaScript**. It showcases beautiful photographs with a clean layout, smooth hover effects, interactive navigation, and a lightbox image viewer.

##  Features

- Responsive design for desktop, tablet, and mobile devices.
- Beautiful image gallery layout.
- Interactive image viewing with Lightbox.
- Next and Previous image navigation.
- Smooth hover effects and transitions.
- Image filtering by categories.
- User-friendly and clean interface.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling, layouts, animations, and responsiveness.
- **JavaScript** – Image navigation, filtering, and lightbox functionality.

##  Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/shashi-pegasuscrew/image-gallery.git
   ```

2. Open the project folder:

   ```bash
   cd image-gallery
   ```

3. Open `index.html` in your browser or use VS Code Live Server.

## 🎯 Project Objective

The objective of this project is to develop an interactive and responsive image gallery while improving practical skills in frontend development using HTML, CSS, and JavaScript.
